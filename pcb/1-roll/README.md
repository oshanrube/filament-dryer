# 1-roll controller board (JLCPCB assembly)

The board for the single-reel dryer: 70 × 100 mm, connectors on the two short ends, every part from JLCPCB's library. It is the shared board (`pcb/`) without the feeder drivers, the second scale, the lane-sensor connectors and the MCP23017. Generated by `python3 pcb/tools/gen_kicad.py --1roll` from the same parts table, so the two boards stay in step.

| File | What |
| --- | --- |
| `dryer-controller-1roll.kicad_sch`, `.kicad_pcb`, `.kicad_pro` | KiCad 7 project. The board is placed (outline, mounting holes, break-off sensor boards, wide heater path) but **not routed yet** |
| `export/dryer-controller-1roll.pdf`, `.net` | Schematic PDF and netlist |
| `jlcpcb/bom-1-roll.csv` | JLCPCB assembly BOM, everything (73 parts) |
| `jlcpcb/bom-1-roll-smt-only.csv`, `jlcpcb/hand-solder-1-roll.csv` | The same split in two: JLCPCB places the SMD parts, you solder the through-hole ones (connectors, XT60, fuse holder, heater terminal, buzzer). Cheaper: those are 7 extended part types at US$3 each, and the Littelfuse fuse holder alone is about US$2.90 |
| `easyeda/dryer-controller-1roll-kicad.zip` | The project packed for EasyEDA Pro (File → Import → KiCad) |
| `libs/`, `fp-lib-table`, `sym-lib-table`, `dryer.kicad_sym` | Footprints and symbols, so the project opens anywhere |

## Differences from the shared board

| Signal | Shared board | 1-roll board |
| --- | --- | --- |
| BTT runout switch (J15 pin 3) | MCP23017 GPA2 | GPIO3, 10 k pull-up R32 |
| Front-panel button (J9) | MCP23017 GPA3 | GPIO20, 10 k pull-up R33 |
| Buzzer (Q4 gate) | MCP23017 GPA4 | GPIO10 |
| Feeders, second scale, lane sensors | U10, U11, U8, J12-J14, J16, J17 | not on this board |

Everything else (power, heater, fans, scale A, sensors, USB, sensor boards SB1/SB2, connector numbers) is the same, so the harness and the wiring diagram are unchanged.

## Checks

Netlist checked pin by pin against the parts table, every pin has a pad, no duplicate designators, and KiCad's DRC on the placed board reports no errors (silkscreen warnings only). The checks in `pcb/README.md` (antenna keep-out, heater copper, XT60 polarity, fuse-holder board thickness) apply here too.
