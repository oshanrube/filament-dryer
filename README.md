# Filament dryer

3D-printed filament dryer boxes, one per printer: heated to 40-70 °C, weighing the reel and reporting to the Printer Control Center over Wi-Fi. Two versions share the same heater, fans, controller, sensors and 12 V feed, so they use the same spares.

| Version | Folder | What it is |
| --- | --- | --- |
| 2-roll feeder | [`2-roll-feeder/`](2-roll-feeder/) | Two reels and a feeder pod; switches to the second reel automatically when the printer reports a runout |
| 1 roll | [`1-roll/`](1-roll/) | One reel, no feeders; smaller and simpler |

**Published plan:** GitHub Pages from `/docs` on `main` (Settings → Pages → Deploy from a branch → `main`, `/docs`). The site has an overview page and one tab per version.

## Layout

| Path | What |
| --- | --- |
| `<version>/page.html` | That version's page content |
| `<version>/bom.csv` | Parts list with AliExpress search terms and approximate prices |
| `<version>/schematic.svg` | Electrical schematic (generated by `<version>/tools/gen_schematic.py`) |
| `<version>/wiring.svg`, `<version>/wiring-table.html` | Wiring diagram and connector table (generated by `tools/gen_wiring.py`) |
| `<version>/images/` | Drawings (1-roll ones generated by `1-roll/tools/gen_drawings.py`) |
| `site/layout.html`, `site/overview.html` | Shared page shell with the tabs, and the overview page |
| `tools/build_site.py` | Builds `docs/` (the published site) from the folders above |
| `docs/` | Generated; don't edit by hand |

## Rebuild

```bash
python3 2-roll-feeder/tools/gen_schematic.py && python3 1-roll/tools/gen_schematic.py && python3 1-roll/tools/gen_drawings.py && python3 tools/gen_wiring.py
```

```bash
python3 tools/build_site.py
```
